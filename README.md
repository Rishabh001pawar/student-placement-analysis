# Student Placement Analysis with Explainable AI

This project analyzes student placement data using machine learning techniques and provides interpretable predictions through SHAP (Explainable AI). It is implemented in a clean and interactive Google Colab notebook.

## 🔗 Open in Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/lavipawar4/student-placement-analysis/blob/main/Placement_Prediction.ipynb)

## ✨ Key Features

- Predicts placement outcomes using features like CGPA, internships, attendance, communication skills, etc.
- Uses *Logistic Regression, Random Forest*, and other models
- Implements *SHAP for explainable AI*
- Visual analysis with *Seaborn and Matplotlib*
- Built on Google Colab for easy access

## 📂 Repository Structure

student-placement-analysis/ ├── Placement_Prediction.ipynb     # Main notebook ├── student_data.csv               # Dataset file ├── README.md                      # Project documentation

## 🧠 Technologies Used

- Python
- Pandas, NumPy
- Scikit-learn
- SHAP
- Matplotlib, Seaborn
- Google Colab

## ✅ How to Use

1. Open the notebook in Google Colab (link above).
2. Run all the cells step-by-step.
3. Upload your own dataset or use the default one.
4. Get predictions and SHAP-based feature interpretation.
