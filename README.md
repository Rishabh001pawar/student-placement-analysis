Student Placement Prediction System
This is my final year project where I made a system that predicts whether a student will get placed or not using machine learning. It uses data like CGPA, internships, communication skills, and more.

in this project What it does:
Takes student details
Predicts if they’ll get placed
Explains why (using SHAP)


Tools Used:
Python, Pandas, Scikit-learn, SHAP
Random Forest (92% accuracy)

Why I made it:
To help students understand what really matters for placements.
